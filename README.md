
# 🔐 Password Guessing Game (Python)

A fun and interactive **Password Guessing Game** built with Python.  
The player chooses a difficulty level (Easy / Medium / Hard), and the program randomly picks a secret word that the player must guess using hints.

---

## 🧩 Features

✅ Choose between **3 difficulty levels** (Easy, Medium, Hard)  
✅ Get **letter-by-letter hints** after each guess  
✅ Tracks **number of attempts**  
✅ Beginner-friendly project  

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/KhadijaCodes-hub/Password-Guessing-Game.git
cd password-guessing-game
````

Run the program:

```bash
python password_guessing_game.py
```
